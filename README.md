# 桌面悬浮窗小工具集

三个常年待在桌面上的小窗口，随时瞄一眼就知道：

- 现在北京几点、美西几点
- 服务器今天跑了多少流量
- 今天有什么财经新闻

不用装大型软件，**下载解压、双击就能用**。

## 三个工具分别是什么

| 工具 | 一句话说明 | 需要自己的服务器吗 |
|---|---|:---:|
| **双时区时钟**<br>`TimeClock.py` | 大字显示北京时间，下面一行显示美西时间；节假日自动变色；还能当番茄钟休息提醒 | ❌ 不需要 |
| **流量监控**<br>`traffic_monitor.py` | 显示你 VPS 的累计上传 / 下载流量，以及当前连不连得上 | ✅ 需要 |
| **新闻阅读**<br>`news_reader.py` | 报纸风格的小窗，贴着你服务器上的一份新闻摘要，每 5 分钟自动刷新 | ✅ 需要 |

三个都是同样的操作手感：

- 没有标题栏，**按住窗口任意位置就能拖动**
- **点右上角的 ⬇ 就能"沉底"** —— 让它退到所有窗口后面，不挡视线
- **按一下快捷键就能叫回来** —— 沉底后它不会出现在任务栏，全靠这个键
- 关掉窗口就彻底退出，不会留后台进程

## 快速开始

### 方式一：直接用打包好的 exe（推荐，不用装 Python）

1. 解压整个文件夹 —— **不能只拿 exe**，旁边的 `_internal` 文件夹是依赖，少了会打不开
2. 双击里面的 `TimeClock.exe` 就能用
3. 第一次打开 Windows 可能弹"已保护你的电脑" → 点 **更多信息 → 仍要运行**

> 时钟**不需要任何配置**，打开就能用。
> 流量监控和新闻阅读要先改一下配置，看下一节。

### 方式二：自己用 Python 运行

```bash
pip install -r requirements.txt
python TimeClock.py
```

`requirements.txt` 里只有三样东西：

```text
paramiko>=3.0      # 连服务器用（流量监控 / 新闻阅读）
tzdata             # 时区数据（Windows 自身不带）
chinesecalendar    # 中国节假日数据（可选，不装只是日期不上色）
```

> 只用时钟的话，其实只需要 `tzdata`；只用另外两个的话，只需要 `paramiko`。

## 第一次使用：要先改配置

流量监控和新闻阅读要连你的服务器，所以得先填三样东西。
打开 `.py` 文件，**最上面有一段"配置区"**，把 `YOUR_` 开头的值换成你自己的：

| 要找的 | 换成什么 | 例子 |
|---|---|---|
| `YOUR_SERVER_IP` | 你服务器的公网 IP | `203.0.113.10` |
| `YOUR_SSH_PORT` | 服务器 SSH 端口，**填数字时把引号去掉** | `"YOUR_SSH_PORT"` → `22` |
| `YOUR_SSH_USER` | 登录用户名 | `root` 或 `ubuntu` |
| `KEY_NAME` | 私钥文件名 | `id_ed25519` |
| `NEWS_PATH` | 新闻窗要读的那个文件（只有新闻阅读需要） | `/home/me/news.txt` |

改完大概长这样：

```python
HOST = "203.0.113.10"
PORT = 22
USER = "ubuntu"
KEY_NAME = "id_ed25519"
```

> 忘了改也没关系 —— 程序会弹窗提醒你"配置还没改"，不会莫名其妙报错。

## 私钥放哪里

用大白话说：程序要**一把钥匙文件**才能登进你的服务器。

两件事千万别做：**别把钥匙写进代码，别把钥匙发给别人。**

程序会按这个顺序找，找到就用：

| 顺序 | 放哪里 | 适合谁 |
|:---:|---|---|
| 1 | exe 或脚本**旁边的同目录** | 想做成"绿色版"，拷走就能跑 |
| 2 | 同目录下的 `key\` 文件夹 | 想稍微藏一下 |
| 3 | **`C:\Users\你的用户名\.ssh\`** | **推荐，最省事** |
| 4 | 配置文件里 `KEY_FILE_HINT` 写的路径 | 兜底 |

**最简单的做法**：把钥匙文件（比如 `id_ed25519`）丢进 `C:\Users\你的用户名\.ssh\` 文件夹，代码一个字都不用改。

> 打包成 exe 之后这一条依然有效，因为它跟着**当前 Windows 用户**走，换电脑也能用。

## 怎么打包 / 怎么发给别人

### 推荐用"文件夹模式"打包（`--onedir`）

打包有两种方式，**强烈建议用文件夹模式**：

| | `--onedir`（推荐） | `--onefile`（单文件） |
|---|---|---|
| 打包出来是什么 | 一个文件夹：`XXX.exe` + `_internal/` | 只有一个 `XXX.exe` |
| 启动速度 | 快，直接开 | 慢 1~3 秒（每次都要先解压） |
| 被杀软误报 | 少 | **多** |
| 怎么发给别人 | 整个文件夹压成 zip | 单个文件 |

**单文件为什么容易被杀软拦？**

因为单文件的本质是"自解压包"：每次双击，它会先在系统临时目录里悄悄解压出几十个文件，
用完再删掉。这种"偷偷释放文件"的动作，和木马的手法很像，所以 Windows 很容易弹"已保护你的电脑"。

文件夹模式没有这个解压动作，干净多了。

> 单文件也不是不能用，手动点「更多信息 → 仍要运行」就行 —— 只是发给别人体验会差。

### 打包命令

先在 PowerShell 里清掉上次的残留：

```powershell
Remove-Item -Recurse -Force build, dist, *.spec -ErrorAction SilentlyContinue
```

然后逐个打包：

```powershell
# 1. 双时区时钟（必须带上时区库和节假日库，否则日期不会上色）
pyinstaller --noconsole --onedir --collect-data tzdata --collect-all chinesecalendar --name TimeClock TimeClock.py

# 2. 流量监控
pyinstaller --noconsole --onedir --name TrafficMonitor traffic_monitor.py

# 3. 新闻阅读
pyinstaller --noconsole --onedir --name NewsReader news_reader.py
```

### 打出来的东西长这样

```text
dist/
├── TimeClock/
│   ├── TimeClock.exe
│   └── _internal/          ← 依赖都在这里，千万别删
├── TrafficMonitor/
│   ├── TrafficMonitor.exe
│   └── _internal/
└── NewsReader/
    ├── NewsReader.exe
    └── _internal/
```

体积参考：`NewsReader.exe` 本身只有 3.7 MB，`_internal/` 里 58 个文件约 38 MB。

### 发给别人时注意

1. **整个文件夹压成 zip**，不能只发 exe（少了 `_internal` 会打不开）
2. 对方解压后双击里面的 `XXX.exe`，**不需要装 Python**
3. 要用到服务器的功能，记得把私钥放到 **exe 旁边**，或者 `C:\Users\用户名\.ssh\`
4. 对方第一次运行可能被拦截，点「更多信息 → 仍要运行」

## 快捷键

三个窗口可以同时开，互不冲突（每个绑的是不同的键）：

| 程序 | 沉底 / 叫回来 |
|---|---|
| 双时区时钟 | `Ctrl + Shift + 1` |
| 流量监控 | `Ctrl + Shift + 2` |
| 新闻阅读 | `Ctrl + Shift + 3` |

按一下：窗口**沉到最底层**，不挡你干正事。
再按一下：**弹回最前面**。

> 沉底之后它就没有任务栏图标了，所以**只能靠这个快捷键叫回来** —— 记不住的话建议写在便签上。

## 常见问题

| 遇到什么 | 怎么办 |
|---|---|
| 双击 exe 弹出"已保护你的电脑" | 点「更多信息 → 仍要运行」；或者改用文件夹模式打包 |
| 双击之后什么都没发生 | 可能弹了"配置还没改"或"找不到私钥"的小窗，仔细找一下；也可能被别的窗口挡住了 |
| 窗口闪一下就不见了 | 配置区还是 `YOUR_` 占位符，改成真实值再打开 |
| 换网络 / 开热点后连不上 | 确认 IP 是公网 IP，并且云厂商的防火墙放行了 SSH 端口 |
| 时钟日期只有灰色，节假日不变色 | 没装 `chinesecalendar`；它目前只收录到 2026 年，往后会先退化成"只看周末" |
| 时钟报 `ZoneInfoNotFoundError` | 没装 `tzdata` |
| 快捷键没反应 | 这个键被别的软件占了，改配置区里的 `HOTKEY` 换一个 |
| 新闻窗一直显示"正在连接…" | 服务器连不上或私钥不对，看窗口右上角的状态点和底部提示 |
| 打包后字体变丑了 | 目标电脑没装"宋体"，程序会自动换成 `Georgia` / `Times` |
| 想把窗口拖到别的位置 | 按住任意位置拖就行，窗口没有标题栏 |

## 给想改代码的人

几个实现上的取舍，供参考：

- **每个 `.py` 都是独立单文件**，配置写在文件顶部，改完直接跑，不需要额外配置文件
- 连服务器用的是 **SSH 长连接**：启动时认证一次，之后每次刷新复用同一条连接，不会频繁登录
- 所有网络操作都在后台线程，界面不会因为网络卡住而假死
- 网络操作都有超时，连续失败会逐次拉长重试间隔，不会疯狂重连

提交代码前建议扫一遍，别把真实 IP / 邮箱 / 私钥推上去：

```bash
grep -rnE "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[a-z]{2,}|BEGIN .*PRIVATE KEY" . --include="*.py"
```

没有任何输出才算安全。另外 git 提交里的 **author 邮箱也是公开的**，建议用 GitHub 的 noreply 地址。
